Alıştırma: ikili arama

Exercise: binary search

Übung: binäre Suche

Görev. search(x) fonksiyonunu yaz: sıralı a dizisinde x değerini ikili arama ile arasın ve bulunduğu indisi döndürsün; yoksa -1. Çalıştır ile denemeni izle, Kontrol et ile cevabını sına.

Task. Write the function search(x): it looks for the value x in the sorted array a with binary search and returns its index, or -1 if it is not there. Use Run to watch your attempt and Check to test your answer.

Aufgabe. Schreibe die Funktion search(x): sie sucht den Wert x im sortierten Array a mit binärer Suche und gibt seinen Index zurück, sonst -1. Mit Ausführen siehst du deinen Versuch, mit Prüfen testest du deine Antwort.

  1. Aranacak aralığı iki sınırla tut: low ve high; başta 0 ve n - 1.
  2. Ortadaki hücreye bak: mid = taban((low + high) / 2). Eşitse bulundu; aranan küçükse high = mid - 1, büyükse low = mid + 1.
  3. Aralık boşalınca (low > high) değer yoktur: -1 döndür.
  1. Keep the range to search between two bounds: low and high, at first 0 and n - 1.
  2. Look at the middle cell: mid = taban((low + high) / 2). If it is equal you found it; if the value is smaller set high = mid - 1, if larger low = mid + 1.
  3. When the range is empty (low > high) the value is not there: return -1.
  1. Halte den Suchbereich zwischen zwei Grenzen: low und high, anfangs 0 und n - 1.
  2. Sieh dir die mittlere Zelle an: mid = taban((low + high) / 2). Ist sie gleich, hast du ihn gefunden; ist der Wert kleiner, setze high = mid - 1, ist er größer, low = mid + 1.
  3. Ist der Bereich leer (low > high), ist der Wert nicht da: gib -1 zurück.

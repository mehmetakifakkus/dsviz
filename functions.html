Instead of writing the same steps again and again, we can define them once with function and call them by name. The v in parentheses is the function's parameter: it receives the value passed in the call. Variables declared with var inside the function (n, t) are local: they exist only while that call runs and are drawn in purple. topNode is declared outside the functions, so it is global and the functions can change it. This block only defines the functions; no list is drawn yet.

Statt dieselben Schritte immer wieder zu schreiben, können wir sie einmal mit function definieren und über ihren Namen aufrufen. Das v in den Klammern ist der Parameter der Funktion: er erhält den Wert, der beim Aufruf übergeben wird. Variablen, die in der Funktion mit var angelegt werden (n, t), sind lokal: sie existieren nur, solange dieser Aufruf läuft, und werden lila gezeichnet. topNode ist außerhalb der Funktionen angelegt, also global, und die Funktionen können ihn ändern. Dieser Block definiert die Funktionen nur; es wird noch keine Liste gezeichnet.

Şimdi fonksiyonları çağıralım. Her çağrı, görselleştirmenin altındaki Çağrı yığını panelinde parametreleri ve yerel değişkenleriyle görünür; çağrı bitince panelden kalkar ve yerel pointer'ları çizimden silinir. return ile döndürülen değer çağrının yerine geçer: var a = pop() satırında a, pop'un döndürdüğü değeri alır.

Now let's call the functions. Each call appears with its parameters and local variables in the Call stack panel below the visualization; when the call ends it leaves the panel and its local pointers are removed from the drawing. The value given by return takes the place of the call: in var a = pop(), a gets the value that pop returns.

Jetzt rufen wir die Funktionen auf. Jeder Aufruf erscheint mit seinen Parametern und lokalen Variablen im Bereich Aufrufstapel unter der Visualisierung; wenn der Aufruf endet, verschwindet er dort und seine lokalen Zeiger werden aus der Zeichnung entfernt. Der mit return zurückgegebene Wert tritt an die Stelle des Aufrufs: in var a = pop() erhält a den Wert, den pop zurückgibt.

Koşul yazarken karşılaştırma şart değildir. if(p) "p bir düğümü gösteriyorsa", if(!p) ise "p null ise" demektir: null, 0 ve false yanlış, bir düğüm ya da sıfırdan farklı bir sayı doğru sayılır. ! (ya da değil) koşulu tersine çevirir. Bu yüzden doğru/yanlış döndüren bir fonksiyon doğrudan koşul olarak kullanılabilir: aşağıdaki döngü yığın boşalana kadar pop yapar.

A condition does not need a comparison. if(p) means "if p points to a node" and if(!p) means "if p is null": null, 0 and false count as false, a node or a non-zero number counts as true. ! (or not) turns a condition around. So a function that returns true or false can be used directly as a condition: the loop below keeps calling pop until the stack is empty.

Eine Bedingung braucht keinen Vergleich. if(p) heißt „wenn p auf einen Knoten zeigt“, if(!p) heißt „wenn p null ist“: null, 0 und false gelten als falsch, ein Knoten oder eine Zahl ungleich null als wahr. ! (oder not) kehrt eine Bedingung um. Deshalb kann eine Funktion, die wahr oder falsch zurückgibt, direkt als Bedingung dienen: die Schleife unten ruft pop auf, bis der Stapel leer ist.

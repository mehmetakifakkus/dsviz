Bağlı Listeler

Linked Lists

Verkettete Listen

Bağlı listelerin (linked list) nasıl çalıştığını, yazdığınız kodu adım adım çizerek gösteren bir eğitim aracı. Kurulum gerektirmez.

A teaching tool that shows how linked lists work by drawing the code you write, step by step. Nothing to install.

Ein Lernwerkzeug, das zeigt, wie verkettete Listen funktionieren, indem es Ihren Code Schritt für Schritt zeichnet. Keine Installation nötig.

Deneme alanı

Playground

Spielwiese

Kodu Çalıştır düğmesiyle ya da kod bloğunun içindeyken CTRL+ENTER ile çalıştırın. Animasyonu görselleştirmenin üstündeki düğmelerle adım adım ileri ve geri oynatabilirsiniz. Kodu değiştirip yeniden çalıştırdığınızda çizim temiz başlar. Değiştirdiğiniz kodu bloğun altındaki bağlantı düğmesiyle paylaşabilirsiniz: bağlantıyı açan kişi aynı sayfayı sizin kodunuzla görür.

Run the code with the Run button, or with CTRL+ENTER while inside the code block. Use the buttons above the visualization to play the animation step by step, forwards and backwards. When you change the code and run it again, the drawing starts clean. You can share your changed code with the link button under a block: whoever opens the link sees the same page with your code.

Führen Sie den Code mit der Schaltfläche Ausführen aus, oder mit STRG+ENTER, während Sie im Codeblock sind. Mit den Schaltflächen über der Visualisierung spielen Sie die Animation Schritt für Schritt vor und zurück ab. Wenn Sie den Code ändern und erneut ausführen, beginnt die Zeichnung sauber. Geänderten Code teilen Sie mit der Link-Schaltfläche unter einem Block: wer den Link öffnet, sieht dieselbe Seite mit Ihrem Code.

Görselleştirmenin altındaki Komut satırı sekmesine tek satırlık kodlar da yazabilirsiniz, Enter ile çalışır.

You can also type one-line commands in the Command line tab below the visualization; Enter runs them.

Im Reiter Befehlszeile unter der Visualisierung können Sie auch einzeilige Befehle eingeben; Enter führt sie aus.

Kodlar, bu iş için geliştirilmiş Düğüm adlı küçük bir dille yazılır. Dili tanımak için Düğüm dili rehberine bakın.

The code is written in Düğüm, a small language made for this purpose. To get to know it, read the guide to the Düğüm language.

Der Code ist in Düğüm geschrieben, einer kleinen Sprache, die eigens dafür entwickelt wurde. Zum Kennenlernen lesen Sie den Leitfaden zur Sprache Düğüm.

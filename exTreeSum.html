Alıştırma: ağaçtaki değerlerin toplamı

Exercise: the sum of the values in a tree

Übung: die Summe der Werte eines Baums

Görev. treeSum(node) fonksiyonunu yaz: node kökünden başlayan ağaçtaki bütün düğümlerin data değerlerinin toplamını döndürsün (boş ağaç için 0). Çalıştır ile denemeni izle, Kontrol et ile cevabını sına.

Task. Write the function treeSum(node): it returns the sum of the data values of all nodes of the tree that starts at node (0 for an empty tree). Use Run to watch your attempt and Check to test your answer.

Aufgabe. Schreibe die Funktion treeSum(node): sie gibt die Summe der data-Werte aller Knoten des Baums ab node zurück (0 für einen leeren Baum). Mit Ausführen siehst du deinen Versuch, mit Prüfen testest du deine Antwort.

  1. Toplam = düğümün kendi değeri + sol alt ağacın toplamı + sağ alt ağacın toplamı.
  2. Boş ağaç (node == null) için 0 döndür: özyinelemenin durma koşulu.
  1. The sum = the value of the node itself + the sum of the left subtree + the sum of the right subtree.
  2. For an empty tree (node == null) return 0: that is where the recursion stops.
  1. Summe = Wert des Knotens selbst + Summe des linken Teilbaums + Summe des rechten Teilbaums.
  2. Für einen leeren Baum (node == null) gib 0 zurück: dort endet die Rekursion.

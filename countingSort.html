Counting Sort (Zählsortierung)

Blokları sırayla çalıştırın. Bir bloğu çalıştırdığınızda üstündeki bloklar da kendiliğinden yeniden çalışır ve çizim temiz başlar. Animasyonu sağdaki düğmelerle adım adım ileri ve geri oynatabilirsiniz.

Şimdiye kadarki bütün sıralamalar değerleri birbiriyle karşılaştırıyordu ve bunun bir alt sınırı vardır: O(n log n). Değerler küçük bir tam sayı aralığındaysa (burada 0 ile 9) karşılaştırmadan sıralamak mümkün: sayarak sıralama her değerden kaç tane olduğunu sayar, sonra değerleri küçükten büyüğe o kadar kez yazar.

All the sorting algorithms so far compared values with each other, and that has a lower bound: O(n log n). If the values are in a small range of integers (here 0 to 9) it is possible to sort without comparing: counting sort counts how many there are of every value, then writes the values from the smallest to the biggest, that many times each.

Alle bisherigen Sortierverfahren verglichen Werte miteinander, und das hat eine untere Schranke: O(n log n). Liegen die Werte in einem kleinen Bereich ganzer Zahlen (hier 0 bis 9), kann man ohne Vergleiche sortieren: Counting Sort zählt, wie oft jeder Wert vorkommt, und schreibt die Werte dann von klein nach groß so oft zurück.

Oynatıcının yanındaki sayaca bakın: karşılaştırma 0! Algoritma yalnızca sayıyor ve yazıyor. count dizisi her değerin sayısını tutar. Süre O(n + k) (k: değer aralığı, burada 10): k küçükse hızlıdır; değerler çok büyük aralıktaysa (ör. 0 ile bir milyar) bellek ve zaman israf olur. Taban sıralaması (radix sort) bu fikri rakam rakam uygulayarak aralığı küçültür.

Look at the counter next to the player: comparisons 0! The algorithm only counts and writes. The array count keeps the number of every value. It takes O(n + k) (k: the range of values, here 10): fast if k is small; if the values are in a huge range (e.g. 0 to a billion) it wastes memory and time. Radix sort applies this idea digit by digit to make the range small.

Sehen Sie auf den Zähler neben dem Player: Vergleiche 0! Der Algorithmus zählt und schreibt nur. Das Array count hält die Anzahl jedes Werts. Es dauert O(n + k) (k: der Wertebereich, hier 10): schnell, wenn k klein ist; liegen die Werte in einem riesigen Bereich (z. B. 0 bis eine Milliarde), verschwendet es Speicher und Zeit. Radixsort wendet die Idee Ziffer für Ziffer an, um den Bereich klein zu machen.

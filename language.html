Düğüm dili: rehber

The Düğüm language: a guide

Die Sprache Düğüm: ein Leitfaden

Bu sitedeki kodlar Düğüm adında küçük bir dille yazılır. Düğüm, veri yapılarını öğretmek için tasarlanmış, JavaScript'e benzeyen bir dildir: her satırı tek tek çalıştırılır ve her satırın veri yapısında ne değiştirdiği tuvalde çizilir. Adı, dilin temel taşı olan düğümden (node) gelir; Türkçede düğüm aynı zamanda iki ipin birbirine bağlandığı yerdir, tıpkı next bağlarının düğümleri birbirine bağlaması gibi.

The code on this site is written in a small language called Düğüm. Düğüm is a JavaScript-like language made for teaching data structures: it runs one line at a time, and what each line changes in the data structure is drawn on the canvas. The name is Turkish for node, the building block of the language; it also means knot, the place where two ropes are tied together, just as next links tie nodes together.

Der Code auf dieser Seite ist in einer kleinen Sprache namens Düğüm geschrieben. Düğüm ist eine JavaScript-ähnliche Sprache zum Lehren von Datenstrukturen: sie führt eine Zeile nach der anderen aus, und was jede Zeile an der Datenstruktur ändert, wird auf der Zeichenfläche gezeichnet. Der Name ist das türkische Wort für Knoten (node), den Grundbaustein der Sprache; er bedeutet auch den Knoten in einem Seil, dort wo zwei Seile verbunden sind, so wie next-Verbindungen Knoten verbinden.

JavaScript bilen biri Düğüm kodunu hemen okur; yine de dil bilerek küçük tutuldu: her satırda tek bir komut vardır, nesneler yerine düğümler ve basit diziler vardır. Böylece öğrenci dile değil, veri yapısına odaklanır. Kodu her sayfada değiştirip yeniden çalıştırabilirsiniz; bu sayfanın blokları da çalışır.

Anyone who knows JavaScript can read Düğüm code right away; still, the language is kept small on purpose: one statement per line, and nodes and simple arrays instead of objects. That way students focus on the data structure, not on the language. You can change and rerun the code on every page; the blocks on this page run too.

Wer JavaScript kennt, kann Düğüm-Code sofort lesen; trotzdem ist die Sprache absichtlich klein gehalten: eine Anweisung pro Zeile, und Knoten und einfache Arrays statt Objekten. So konzentrieren sich Lernende auf die Datenstruktur, nicht auf die Sprache. Sie können den Code auf jeder Seite ändern und erneut ausführen; auch die Blöcke dieser Seite laufen.

Değişkenler ve sayılar

Variables and numbers

Variablen und Zahlen

Değişkenler var ile tanımlanır (virgülle birkaç tane birden: var a = 1, b = 2); sonra var olmadan yeni değer alabilir. Sayılarla + - * / % işlemleri yapılır, n++, n--, n += 2 de olur. Doğru/yanlış değerleri true / false (ya da doğru / yanlış) ile yazılır. Metin (string) yalnızca print içinde kullanılır; parçalar + ile birleştirilir. Matematik için taban (aşağı yuvarlama), tavan (yukarı yuvarlama), karekök ve mutlak fonksiyonları vardır. Değişkenler panelinde her değişkenin değeri görünür.

Variables are declared with var (several at once with commas: var a = 1, b = 2); afterwards they take new values without var. Numbers support + - * / %, and n++, n--, n += 2. True/false values are written true / false (or doğru / yanlış). Text (strings) is used only in print; the parts are joined with +. For math there are taban (round down), tavan (round up), karekök (square root) and mutlak (absolute value). The Variables panel shows the value of every variable.

Variablen werden mit var deklariert (mehrere auf einmal mit Kommas: var a = 1, b = 2); danach bekommen sie ohne var neue Werte. Zahlen kennen + - * / % sowie n++, n--, n += 2. Wahrheitswerte schreibt man true / false (oder doğru / yanlış). Text (Strings) gibt es nur in print; die Teile werden mit + verbunden. Für Mathematik gibt es taban (abrunden), tavan (aufrunden), karekök (Quadratwurzel) und mutlak (Betrag). Das Feld Variablen zeigt den Wert jeder Variable.

Düğümler ve bağlar

Nodes and links

Knoten und Verbindungen

new Node(değer) yeni bir düğüm oluşturur (new yazılmasa da olur); değer bir ifade de olabilir. İkinci bir değer verilirse yeni düğümün next'i olur: head = new Node(0, head) başa ekler. Her düğümün data (değer) ve next (sonraki düğüm) alanları vardır; next başta null'dır. Bir değişken düğümün kendisini değil, onu gösteren bir pointer'ı tutar: p = x yeni bir düğüm oluşturmaz, iki değişken aynı düğümü gösterir. Alanlar zincirlenebilir: x.next.next.data. delete bir düğümü siler; ona hâlâ ulaşan bir bağ ya da pointer kalmamasına dikkat etmek programcının işidir. Artık hiçbir yerden ulaşılamayan düğümler soluk çizilir ve uyarı verilir.

new Node(value) makes a new node (new may be left out); the value can be an expression. A second value becomes the new node's next: head = new Node(0, head) inserts at the head. Every node has the fields data (its value) and next (the next node); next starts as null. A variable does not hold the node itself but a pointer to it: p = x makes no new node, the two variables point to the same node. Fields can be chained: x.next.next.data. delete deletes a node; making sure that no link or pointer still leads to it is the programmer's job. Nodes that nothing reaches any more are drawn faded, with a warning.

new Node(Wert) erzeugt einen neuen Knoten (new darf fehlen); der Wert kann ein Ausdruck sein. Ein zweiter Wert wird das next des neuen Knotens: head = new Node(0, head) fügt am Anfang ein. Jeder Knoten hat die Felder data (sein Wert) und next (der nächste Knoten); next ist anfangs null. Eine Variable enthält nicht den Knoten selbst, sondern einen Zeiger auf ihn: p = x erzeugt keinen neuen Knoten, beide Variablen zeigen auf denselben Knoten. Felder lassen sich verketten: x.next.next.data. delete löscht einen Knoten; dafür zu sorgen, dass keine Verbindung und kein Zeiger mehr zu ihm führt, ist Aufgabe des Programmierers. Knoten, die nichts mehr erreicht, werden blass gezeichnet, mit einer Warnung.

Koşullar ve döngüler

Conditions and loops

Bedingungen und Schleifen

if / else, while ve for JavaScript'teki gibidir; gövde tek satırsa süslü parantez gerekmez. Karşılaştırmalar == != < <= > >=, birleştirmeler &&, ||, ! (ya da and, or, not) ile yazılır. Bir pointer tek başına da koşul olabilir: while(p), p != null demektir. Her koşulun doğru mu yanlış mı çıktığı editörde yeşil ya da kırmızıyla işaretlenir. Sonsuz döngüye karşı bir döngü en fazla 1000 tur döner.

if / else, while and for work as in JavaScript; a one-line body needs no braces. Comparisons are written == != < <= > >=, combinations &&, ||, ! (or and, or, not). A pointer on its own can be a condition: while(p) means p != null. Whether each condition is true or false is marked green or red in the editor. To stop endless loops, a loop runs at most 1000 rounds.

if / else, while und for funktionieren wie in JavaScript; ein einzeiliger Rumpf braucht keine geschweiften Klammern. Vergleiche schreibt man == != < <= > >=, Verknüpfungen &&, ||, ! (oder and, or, not). Ein Zeiger allein kann eine Bedingung sein: while(p) bedeutet p != null. Ob eine Bedingung wahr oder falsch ist, wird im Editor grün oder rot markiert. Gegen Endlosschleifen läuft eine Schleife höchstens 1000 Runden.

Fonksiyonlar

Functions

Funktionen

function ile tanımlanan fonksiyonlar parametre alır ve return ile değer döndürür; tanımından önce de çağrılabilir. Fonksiyonun kendi yerel değişkenleri vardır ve global değişkenleri görür. Her çağrı Çağrı yığını panelinde yerel değişkenleriyle görünür; özyinelemede derin çağrıların pointer'ları p₂, p₃ diye adlandırılır. Sonsuz özyinelemeye karşı en fazla 200 çağrı iç içe girebilir. Çağrı bir ifadenin içinde de olur: 1 + count(p.next), t.left = insert(t.left, v).

Functions are defined with function, take parameters and give back a value with return; they can be called before the line that defines them. A function has its own local variables and sees the global ones. Every call appears in the Call stack panel with its locals; in a recursion the pointers of deeper calls are named p₂, p₃. To stop endless recursion, at most 200 calls can be nested. A call can be part of an expression: 1 + count(p.next), t.left = insert(t.left, v).

Funktionen werden mit function definiert, nehmen Parameter und geben mit return einen Wert zurück; man kann sie schon vor der Zeile aufrufen, die sie definiert. Eine Funktion hat eigene lokale Variablen und sieht die globalen. Jeder Aufruf erscheint im Aufrufstapel mit seinen lokalen Variablen; bei einer Rekursion heißen die Zeiger tieferer Aufrufe p₂, p₃. Gegen endlose Rekursion können höchstens 200 Aufrufe verschachtelt sein. Ein Aufruf kann Teil eines Ausdrucks sein: 1 + count(p.next), t.left = insert(t.left, v).

Türkçe anahtar kelimeler

Turkish keywords

Türkische Schlüsselwörter

Düğüm, programlamaya ana dilinde başlamak isteyenler için anahtar kelimelerin Türkçelerini de tanır: eğer (if), değilse (else), yinele (while), fonksiyon (function), döndür (return), değil (not), doğru (true), yanlış (false). Değişken adlarında Türkçe harfler kullanılabilir. İki yazım aynı programda karışık da kullanılabilir.

For those who want to start programming in their mother tongue, Düğüm also knows Turkish versions of the keywords: eğer (if), değilse (else), yinele (while), fonksiyon (function), döndür (return), değil (not), doğru (true), yanlış (false). Variable names may contain Turkish letters. Both spellings can even be mixed in one program.

Für alle, die in ihrer Muttersprache mit dem Programmieren beginnen wollen, kennt Düğüm auch türkische Fassungen der Schlüsselwörter: eğer (if), değilse (else), yinele (while), fonksiyon (function), döndür (return), değil (not), doğru (true), yanlış (false). Variablennamen dürfen türkische Buchstaben enthalten. Beide Schreibweisen lassen sich sogar in einem Programm mischen.

Diziler

Arrays

Arrays

new Array(n) (ya da new Dizi(n)) n hücreli bir dizi oluşturur; hücrelerin hepsi başta null'dır. t[i] i numaralı hücredir (0'dan başlar); bir düğüm, bir sayı ya da null tutabilir. Hücre okumak her ifadede olur: var p = t[k], n.next = t[k], t[k].data. Hücreye yazmak t[i] = … ile yapılır. Dizi tuvalin solunda dikey hücreler olarak çizilir; bir hücre bir düğümü gösteriyorsa, o düğümden başlayan zincir hücrenin satırına yerleşir. Bu tam olarak zincirlemeli hash tablosunun görüntüsüdür (Örnekler menüsündeki hash tablosu sayfasına bakın). Bir dizi en fazla 50 hücreli olabilir; dizinin dışındaki bir indise yazmak açıklamalı bir hata verir.

new Array(n) (or new Dizi(n)) makes an array of n cells; all cells start as null. t[i] is cell number i (counting from 0); it can hold a node, a number or null. Reading a cell works in any expression: var p = t[k], n.next = t[k], t[k].data. A cell is written with t[i] = …. The array is drawn as a column of cells on the left of the canvas; when a cell points to a node, the chain starting at that node is placed on the cell's row. That is exactly the picture of a hash table with chaining (see the hash table page in the Examples menu). An array can have at most 50 cells; writing to an index outside the array gives an explained error.

new Array(n) (oder new Dizi(n)) erzeugt ein Array mit n Zellen; alle Zellen sind anfangs null. t[i] ist die Zelle Nummer i (ab 0 gezählt); sie kann einen Knoten, eine Zahl oder null enthalten. Eine Zelle lesen geht in jedem Ausdruck: var p = t[k], n.next = t[k], t[k].data. Geschrieben wird eine Zelle mit t[i] = …. Das Array wird links auf der Zeichenfläche als Spalte von Zellen gezeichnet; zeigt eine Zelle auf einen Knoten, steht die Kette ab diesem Knoten in der Zeile der Zelle. Genau so sieht eine Hashtabelle mit Verkettung aus (siehe die Seite zur Hashtabelle im Menü Beispiele). Ein Array kann höchstens 50 Zellen haben; das Schreiben an einen Index außerhalb des Arrays gibt einen erklärten Fehler.

Çift yönlü listeler ve ağaçlar

Doubly linked lists and trees

Doppelt verkettete Listen und Bäume

Düğümlerin next'ten başka üç bağ alanı daha vardır. Kodda .prev geçince düğümler çift yönlü liste düğümü olarak çizilir: [prev | değer | next]. .left ya da .right geçince ağaç düğümü olarak çizilir: [left | değer | right]; düğümler derinliklerine göre satırlara yerleşir. Örnekler menüsündeki çift yönlü liste ve ağaç sayfalarına bakın.

Besides next, nodes have three more link fields. When the code uses .prev, nodes are drawn as doubly linked list nodes: [prev | value | next]. When it uses .left or .right, they are drawn as tree nodes: [left | value | right], and nodes are placed in rows by their depth. See the doubly linked list and tree pages in the Examples menu.

Neben next haben Knoten drei weitere Verbindungsfelder. Verwendet der Code .prev, werden Knoten als Knoten einer doppelt verketteten Liste gezeichnet: [prev | Wert | next]. Verwendet er .left oder .right, werden sie als Baumknoten gezeichnet: [left | Wert | right], und die Knoten stehen nach ihrer Tiefe in Zeilen. Siehe die Seiten zu doppelt verketteten Listen und Bäumen im Menü Beispiele.

Komut satırı ve hatalar

The command line and errors

Befehlszeile und Fehler

Görselleştirmenin altındaki Komut satırı sekmesine tek satırlık kod yazılır ve Enter ile çalışır: x.next.data yazınca değeri, x yazınca listenin kendisi görünür (bir ağaç {data, left, right} olarak). Bir hata olunca hangi satırda ne olduğu açıklanır ve satır editörde kırmızıyla işaretlenir: örneğin null bir pointer'ın alanına erişmek, tanımlanmamış bir değişken, kapanmamış bir parantez. Bazı adlar tarayıcıda ayrılmıştır (ör. top, name); onların yerine başka bir ad seçmek gerekir.

In the Command line tab under the visualization you type a single line and run it with Enter: typing x.next.data shows its value, typing x shows the list itself (a tree as {data, left, right}). When something goes wrong, the message says on which line and what happened, and the line is marked red in its editor: for example reading a field of a null pointer, a variable that was never defined, or a bracket that was not closed. Some names are reserved by the browser (e.g. top, name); choose another name instead.

In der Registerkarte Befehlszeile unter der Visualisierung tippt man eine einzelne Zeile und führt sie mit Enter aus: x.next.data zeigt den Wert, x die Liste selbst (ein Baum als {data, left, right}). Geht etwas schief, sagt die Meldung, in welcher Zeile was passiert ist, und die Zeile wird im Editor rot markiert: zum Beispiel beim Lesen eines Feldes eines null-Zeigers, bei einer nie definierten Variable oder einer nicht geschlossenen Klammer. Einige Namen sind im Browser reserviert (z. B. top, name); wählen Sie stattdessen einen anderen Namen.

JavaScript'ten farkları

Differences from JavaScript

Unterschiede zu JavaScript

Her satırda tek komut olur ve satır sonunda ; gerekmez. Nesne ve metin değişkeni yoktur; veri yapıları düğümler ve düğüm tutan dizilerle kurulur. Fonksiyon içinde fonksiyon tanımlanamaz. Bir çağrının sonucunun alanı doğrudan okunamaz (pop().data yerine önce var t = pop()). Dilin grameri grammer.pegjs dosyasındadır (PEG.js); sayfa açılınca tarayıcıda derlenir.

One statement per line, and no ; needed at the end of a line. There are no objects or text variables; data structures are built from nodes and arrays of nodes. A function cannot be defined inside another function. The field of a call's result cannot be read directly (instead of pop().data, first var t = pop()). The grammar of the language is in the file grammer.pegjs (PEG.js); it is compiled in the browser when a page opens.

Eine Anweisung pro Zeile, und am Zeilenende ist kein ; nötig. Es gibt keine Objekte oder Textvariablen; Datenstrukturen werden aus Knoten und Arrays von Knoten gebaut. Eine Funktion kann nicht innerhalb einer anderen Funktion definiert werden. Das Feld eines Aufrufergebnisses kann man nicht direkt lesen (statt pop().data zuerst var t = pop()). Die Grammatik der Sprache steht in der Datei grammer.pegjs (PEG.js); sie wird beim Öffnen einer Seite im Browser übersetzt.

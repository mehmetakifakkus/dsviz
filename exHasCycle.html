Alıştırma: listede döngü var mı?

Exercise: does the list have a cycle?

Übung: hat die Liste einen Zyklus?

Görev. hasCycle(head) fonksiyonunu yaz: bir düğümün next'i listenin önceki bir düğümüne dönüyorsa (döngü) true, liste null ile bitiyorsa false döndürsün. Döngülü listede kodun sonsuza kadar dönmemeli. Çalıştır ile denemeni izle, Kontrol et ile cevabını sına.

Task. Write the function hasCycle(head): it returns true if the next of some node leads back to an earlier node of the list (a cycle), and false if the list ends with null. With a cycle your code must not run forever. Use Run to watch your attempt and Check to test your answer.

Aufgabe. Schreibe die Funktion hasCycle(head): sie gibt true zurück, wenn das next eines Knotens zu einem früheren Knoten der Liste zurückführt (ein Zyklus), und false, wenn die Liste mit null endet. Bei einem Zyklus darf dein Code nicht ewig laufen. Mit Ausführen siehst du deinen Versuch, mit Prüfen testest du deine Antwort.

  1. Listeyi iki pointer ile dolaş: biri her turda bir, diğeri iki düğüm ilerlesin.
  2. Döngü varsa hızlı olan yavaş olana yetişir, yani ikisi aynı düğümü gösterir: true.
  3. Hızlı olan null'a ulaşırsa (ya da next'i null ise) döngü yoktur: false.
  1. Walk the list with two pointers: one moves one node per round, the other two nodes.
  2. If there is a cycle the fast one catches up with the slow one, so both point to the same node: true.
  3. If the fast one reaches null (or its next is null) there is no cycle: false.
  1. Laufe mit zwei Zeigern durch die Liste: einer geht pro Runde einen Knoten weiter, der andere zwei.
  2. Gibt es einen Zyklus, holt der schnelle den langsamen ein, beide zeigen auf denselben Knoten: true.
  3. Erreicht der schnelle null (oder ist sein next null), gibt es keinen Zyklus: false.

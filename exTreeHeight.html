Alıştırma: ağacın yüksekliği

Exercise: the height of a tree

Übung: die Höhe eines Baums

Görev. height(node) fonksiyonunu yaz: node kökünden başlayan ağacın yüksekliğini (en uzun yoldaki düğüm sayısını) döndürsün. Boş ağacın yüksekliği 0, tek düğümün 1. Çalıştır ile denemeni izle, Kontrol et ile cevabını sına.

Task. Write the function height(node): it returns the height of the tree that starts at node (the number of nodes on the longest path). An empty tree has height 0, a single node 1. Use Run to watch your attempt and Check to test your answer.

Aufgabe. Schreibe die Funktion height(node): sie gibt die Höhe des Baums ab node zurück (die Anzahl der Knoten auf dem längsten Pfad). Ein leerer Baum hat die Höhe 0, ein einzelner Knoten 1. Mit Ausführen siehst du deinen Versuch, mit Prüfen testest du deine Antwort.

  1. Özyineleme kullan: bir ağacın yüksekliği, alt ağaçlarının yüksekliklerinden birine bağlıdır.
  2. Boş ağaç (node == null) için 0 döndür; bu özyinelemenin durma koşulu.
  3. Sol ve sağ alt ağacın yüksekliğini hesapla, büyüğünü al ve 1 ekle.
  1. Use recursion: the height of a tree depends on the heights of its subtrees.
  2. For an empty tree (node == null) return 0; that is where the recursion stops.
  3. Compute the height of the left and the right subtree, take the larger one and add 1.
  1. Benutze Rekursion: die Höhe eines Baums hängt von den Höhen seiner Teilbäume ab.
  2. Für einen leeren Baum (node == null) gib 0 zurück; dort endet die Rekursion.
  3. Berechne die Höhe des linken und des rechten Teilbaums, nimm die größere und addiere 1.

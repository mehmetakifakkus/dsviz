Alıştırma: liste sıralı mı?

Exercise: is the list sorted?

Übung: ist die Liste sortiert?

Görev. isSorted(head) fonksiyonunu yaz: liste küçükten büyüğe sıralıysa (eşit değerler yan yana olabilir) true, değilse false döndürsün. Boş liste ve tek düğüm sıralıdır. Çalıştır ile denemeni izle, Kontrol et ile cevabını sına.

Task. Write the function isSorted(head): it returns true if the list is sorted from small to large (equal values may sit next to each other), otherwise false. An empty list and a single node are sorted. Use Run to watch your attempt and Check to test your answer.

Aufgabe. Schreibe die Funktion isSorted(head): sie gibt true zurück, wenn die Liste von klein nach groß sortiert ist (gleiche Werte dürfen nebeneinander stehen), sonst false. Eine leere Liste und ein einzelner Knoten sind sortiert. Mit Ausführen siehst du deinen Versuch, mit Prüfen testest du deine Antwort.

  1. Listeyi dolaşırken her düğümü bir sonrakiyle karşılaştır.
  2. Bir düğüm sonrakinden büyükse liste sıralı değildir: hemen false döndür.
  3. Döngü bir şey bulmadan biterse true döndür.
  1. While walking the list compare every node with the next one.
  2. If a node is larger than the next, the list is not sorted: return false at once.
  3. If the loop ends without finding anything, return true.
  1. Vergleiche beim Durchlaufen jeden Knoten mit dem nächsten.
  2. Ist ein Knoten größer als der nächste, ist die Liste nicht sortiert: gib sofort false zurück.
  3. Endet die Schleife, ohne etwas zu finden, gib true zurück.

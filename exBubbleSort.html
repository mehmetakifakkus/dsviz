Alıştırma: kabarcık sıralama

Exercise: bubble sort

Übung: Bubblesort

Görev. sortArray() fonksiyonunu yaz: a dizisinin n hücresini küçükten büyüğe sıralasın (dizinin kendisini değiştirerek). Çalıştır ile denemeni izle, Kontrol et ile cevabını sına.

Task. Write the function sortArray(): it sorts the n cells of the array a from small to large (changing the array itself). Use Run to watch your attempt and Check to test your answer.

Aufgabe. Schreibe die Funktion sortArray(): sie sortiert die n Zellen des Arrays a von klein nach groß (indem sie das Array selbst ändert). Mit Ausführen siehst du deinen Versuch, mit Prüfen testest du deine Antwort.

  1. Yan yana iki hücreyi karşılaştır: soldaki büyükse yerlerini değiştir.
  2. Bunu dizinin başından sonuna kadar yap; en büyük değer sona "kabarır". Sonra sondaki sıralı kısmı bir azaltıp yine yap.
  3. Yer değiştirmek için geçici bir değişken kullan: var t = a[j], a[j] = a[j + 1], a[j + 1] = t.
  1. Compare two neighbouring cells: if the left one is larger, swap them.
  2. Do this from the start of the array to the end; the largest value "bubbles" to the end. Then do it again with the sorted part at the end one shorter.
  3. Use a temporary variable to swap: var t = a[j], a[j] = a[j + 1], a[j + 1] = t.
  1. Vergleiche zwei benachbarte Zellen: ist die linke größer, tausche sie.
  2. Tu das vom Anfang bis zum Ende des Arrays; der größte Wert „blubbert“ ans Ende. Dann noch einmal, mit einem um eins kürzeren sortierten Teil am Ende.
  3. Benutze zum Tauschen eine Hilfsvariable: var t = a[j], a[j] = a[j + 1], a[j + 1] = t.
